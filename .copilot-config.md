# GitHub Copilot Automation Configuration

## 🤖 Copilot Automation Rules for core-api-services

### PR Review Automation

**Triggers:**
- `review: auto` → Genera automáticamente sugerencias
- `security: scan` → Security scan con Bandit
- `test: run` → Ejecuta pytest
- `api: validate` → Valida API schema

### Auto-Merge Rules

```yaml
Auto-merge cuando:
  - Pylint pass ✅
  - Tests pass (pytest) ✅
  - Security scan pass ✅
  - No breaking API changes ✅
```

### Critical Areas for Review

```yaml
Require manual review:
  - Database migrations
  - Authentication changes
  - Authorization changes
  - API contract changes
  - Third-party integrations
```

### Copilot Commands

```
@copilot review: api               # Review API changes
@copilot validate: migrations      # Validate DB migrations
@copilot check: security           # Security scan
@copilot generate: docs            # Generate API docs
```
